# 📦 DropPortal

A lightweight, fast, and full-stack Flask web application designed for seamless file sharing across devices. Upload files with ease and retrieve them via generated download links or QR codes.

---

## ✨ Features

- 📤 **Simple File Uploads:** Quickly drag & drop or select files to host.
- 🔗 **Shareable Links:** Generates instant download URLs for easy sharing.
- 📱 **QR Code Integration:** Easily scan to access download pages on mobile devices.
- 🎨 **Responsive UI:** Styled cleanly with custom CSS and vanilla JavaScript.
- ⚡ **Lightweight Backend:** Powered by Python and Flask for fast response times.

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript
- **Deployment:** Render

---

## 🚀 Getting Started

Follow these steps to set up and run DropPortal locally on your machine.

### 📋 Prerequisites

Ensure you have Python installed on your system:
- Python 3.8+ 

### 🔧 Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/AkkhileshCod3s/dropportal.git](https://github.com/AkkhileshCod3s/dropportal.git)
   cd dropportal

2. **Create and activate a virtual environment:**
   - **On macOS/Linux:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
   - **On Windows:**
     ```bash
     python -m venv venv
     venv\Scripts\activate
     ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt

4. **Run the application:**
   ```bash
   python app.py

5. **Access the app:**
   Open your browser and navigate to `http://127.0.0.1:5000`.
